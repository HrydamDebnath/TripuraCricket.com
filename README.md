# Hrydam Debnath Cricket Profile

Replace `https://YOUR-DOMAIN.example/` with your real domain in `index.html`, `robots.txt`, and `sitemap.xml`, then deploy the files to a public HTTPS website.

The design is intentionally modeled after a conventional sports/player profile: player header, player details card, statistics, batting/bowling descriptions, club associations, career/leadership timeline, and career highlights.

Google indexing and ranking are not guaranteed. Submit the deployed URL and sitemap in Google Search Console.
